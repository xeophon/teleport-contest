# C Parity Audit 272: Tiphat Nonresident Shopkeeper Sell Speech

## Sources

- `nethack-c/upstream/src/sounds.c:688-714`: `domonnoise()` skips silent non-shopkeepers, forces actual shopkeepers to `MS_SELL`, and routes hallucinated geckos to `MS_SELL`.
- `nethack-c/upstream/src/sounds.c:733-743`: `MS_SELL` calls `shk_chat()` unless the hallucination gag is selected.
- `nethack-c/upstream/src/shk.c:5521-5536`: `shk_chat()` has a deterministic branch for shopkeeper-type monsters that are not actual resident shopkeepers.
- `nethack-c/upstream/src/sounds.c:1449-1528`: worn-helmet `#tip` prints the doffing line, clears wait strategy before response, intercepts visible peaceful humanoids before `domonnoise()`, and maps invisible responders.

## JS Coverage

- `tipHatMonsterSound()` now infers `sell` for actual `isshk` monsters and shopkeeper-type fixtures.
- Explicit `MS_SELL` still normalizes through the existing `MS_` sound-name path.
- Nonhallucinating shopkeeper-type monsters with `!isshk` now use the C `shk_chat()` nonresident line:
  - `<Monnam> asks whether you've seen any untended shops recently.`
- Hallucinated nonresident/gecko `MS_SELL` keeps the existing GEICO-style speech.
- Hallucinated resident shopkeepers and all nonhallucinating resident `isshk` shopkeeper chat remain deferred instead of inventing stateful `shk_chat()` output.

## Tests

Focused canaries in `test/shop-billing-helpers.test.mjs` cover:

- an invisible nonresident shopkeeper-type `MS_SELL` target saying the untended-shops line without RNG,

## Remaining Gaps

- Resident `shk_chat()` branches remain open: angry, following, bill rows, debit, credit, robbed, surcharge, cash thresholds, Izchak, and generic shoplifter chatter.
- Hallucinating actual resident shopkeepers still need the C `rn2(2)` split between `shk_chat()` and the GEICO-style line.
- The actual-shopkeeper exemption from silent monster speech is not fully modeled for polymorphed/silent `isshk` monsters.
- Mute, deaf, limb, pronoun, bill total, shop inventory, and shop room state variants are outside this seed-free slice.
- Broader shared `domonnoise()` and `#chat` remain separate from directed helmet tipping.
