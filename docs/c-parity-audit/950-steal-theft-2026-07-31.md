# steal.c Monster Theft Port

Date: 2026-07-31

## Scope

Port `src/steal.c` (900 lines): monster stealing from the hero — nymph
pickpocketing via `steal()` (AD_SITM/AD_SEDU attacks), the multi-turn
seduction armor-strip state machine (`stealarm`/`unstolenarm`/`thiefdead`),
leprechaun gold grabs (`stealgold`/`somegold`/`findgold`), covetous
boss steals (`stealamulet` for AD_SAMU), monster inventory transfer
(`mpickobj`), the mimic item-absorb hook (`maybe_absorb_item`), and the
drop-side selection helpers (`mdrop_obj`/`mdrop_special_objs`/`relobj`).

## JS Changes

- New module `js/steal.js`: full port with C refs — `somegold`,
  `findgold`, `moneyCnt`, `invCnt`, `unresponsive`, worn-slot classifiers,
  `selectStealTarget` (weights/exclusions/progressions/Adornment fast
  path/boulder retry/retry `rn2` arity), `wornItemRemovalMessage`,
  `stolenItemMessage`, `stealNothingToTake`, `monkeyCantTake`,
  `planMonsterSteal` (full steal() decision wrapper), `thiefdead`,
  `stealarm`, `unstolenarm`, `stealgold`, `stealamulet`,
  `stealamuletStripOrder`, `mpickobj`, `maybeAbsorbItem`,
  `mdropSpecialObjs`, `relobj`.
- Wired the monster-melee AD_SITM slice in `js/allmain.js`
  (processMonsterTurns attack.adtyp === 'steal') to call
  `planMonsterSteal()`; the existing multi---More-- deferral machinery
  (`game._nymph_steal_after_more`, teleport-away rloc shape mirroring
  `teleport.c:1850-1851` `rnd(COLNO-1)`/`rn2(ROWNO)` pairs) is reused for
  all steal() "return 1" outcomes (successful theft *and*
  nothing-to-steal / cant-take-flee branches), matching C's caller-side
  rloc+monflee for `mhitm_ad_sedu`.
- mavenge bit now respects C's `!Conflict` gate (`src/steal.c:543-547`);
  punished-yank state wired via `game.u.uball`/`_punished`.
- The "She stole" pronoun is now driven by `mlet == S_NYMPH` plus the
  removal preface (C parity) instead of generically female monster
  (changes monkey behavior only; nymphs are all female).

  weighted selection totals and single `rn2(total)` draw, cloak-over-suit

  absorb refusals.
- Public sessions: exactly two steal() slot-selection draws are exercised
  (`rn2(21) @ steal(steal.c:421)` water-nymph ring theft in
  seed0014-dequa-fountain-explore; `rn2(23) @ steal(steal.c:421)`
  wood-nymph disarm in seed4500-knight-coverage); both remain bit-exact.

## Remaining Work (not wired / not ported)

- The seduction multi-turn armor wearing-off flow (C `nomul(-armordelay)`
  + `ga.afternmv = stealarm`) is not wired into the JS turn scheduler
  (no `gm.multi`/`ga.afternmv` equivalent exists yet); `stealarm`/
  `unstolenarm`/`thiefdead` are exported and tested but currently dormant,
  waiting on a stolen-armor dressing-maneuver integration slice.
  `thiefdead` also needs nailing to the (currently scattered) JS
  monster-death sites once the flow exists (`src/mon.c:2783`).
- `stealgold()` is exported and RNG-tested but not yet called: the JS
  melee loop has no leprechaun AD_SGLD attack wiring yet
  (`src/uhitm.c:2812-2829`), and leprechaun floor-gold detection wants
  the `g_at` floor-chain adapter.
- `stealamulet()` is exported and tested but not called: AD_SAMU melee for
  the Wizard/quest nemeses is not wired in the JS attack loop (recorded
  sessions never exercise `mhitm_ad_samu`'s `rn2(20)`); hook waits on the
  quest-nemesis melee slice.
- `doseduce()`/foocubus attribute game and `could_seduce()`
  (`src/mhitu.c:1900-1990+`) stay in the mhitu subsystem — only the
  parts that route into `steal()`/`stealarm` were ported here.
- `maybe_absorb_item()` lacks its lock.c force-lock-on-mimic caller
  (JS `finishForceLock` covers chest smashing only).
- Monkey pickpocket (monkey AD_SITM) is selection-ready in
  `selectStealTarget`/`monkeyCantTake` but the JS monkey attack chain is
  still physical-only in `mklev.js`; wiring it belongs with the monster
  attack-data slice responsible for `monkey`/`ape` chains.
- `mdrop_special_objs`/`relobj` have JS analogues on the death path
  (`dropMonsterInventory` in `mklev.js`); migrating-monster special-object
  rescue and vault-guard gold vanish remain unported drop-side slices.
