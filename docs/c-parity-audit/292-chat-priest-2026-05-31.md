## Sources

- `nethack-c/upstream/src/sounds.c:1246-1408`: `#chat` runs `dochat()`, selects an adjacent target, lets priests bypass the normal helpless/sleeping no-talk filter, clears wait strategy, and calls `domonnoise()`.

## JS Changes

- Added a priest-specific `#chat` path in `chatDirection` that reuses the C-shaped priest speaker helper added for directed helmet tipping.
- `#chat` now clears wait strategy before priest speech, maps invisible priests after a response, and consumes a move like C `domonnoise()`.
- Deaf `#chat` to a visible priest now reports the C-shaped inaudible response before priest speech, without incrementing gnostic conduct or consuming priest RNG.
- Visible priests no longer fall through to empty-space handling under `#chat`; they use priest speech.
- Helpless priests are allowed through `#chat`, wake up, clear `msleeping`/`mfrozen`, become hostile, and use the C cranky table with `rn2(3)`.
- Directed `#tip` behavior remains unchanged: helpless targets are still filtered before `domonnoise()` in that path.
