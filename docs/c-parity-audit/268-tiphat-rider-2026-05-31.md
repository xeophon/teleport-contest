# C Parity Audit 268: Tiphat Rider Speech

## Sources

- `nethack-c/upstream/include/monflag.h:50`: `MS_RIDER` is the Astral Rider speech sound.
- `nethack-c/upstream/include/monsters.h:3154-3173`: Pestilence and Famine use `MS_RIDER` and have `M1_HUMANOID`.
- `nethack-c/upstream/src/sounds.c:1193-1219`: non-Death `MS_RIDER` skips all Death-specific branches and sets `verbl_msg = "Who do you think you are, War?"`.
- `nethack-c/upstream/src/sounds.c:1229-1238`: non-Death verbal messages are emitted with normal quoted speech.
- `nethack-c/upstream/src/sounds.c:1503-1528`: directed `tiphat()` clears wait strategy, intercepts visible humanoids before `domonnoise()`, and maps non-visible successful responders as invisible.
- `nethack-c/upstream/src/pickup.c:3668-3671`: worn-helmet `#tip` spends command time when `tiphat()` succeeds.

## JS Coverage

- `tipHatMonsterSound()` now infers Rider speech for Pestilence and Famine because generated JS monster data does not carry `msound` metadata for them.
- Explicit `MS_RIDER` still flows through the existing `MS_` normalization to `rider`.
- `tipHatMonsterNoise()` implements only the deterministic non-Death Rider verbal line: `"Who do you think you are, War?"`.
- Death remains out of scope for this slice because C has novel tribute, random quote, and Sandman branches, plus Death-specific all-caps unquoted speech.
- `tipHatMonsterHumanoid()` treats Death, Pestilence, and Famine as humanoid so visible directed `#tip` stays on the C visible humanoid response path before any Rider speech.

- Shopkeeper `MS_SELL`, quest leaders/nemeses/guardians, priests, vampires, Oracle, seduction, and bribe speech remain separate sound gaps.
