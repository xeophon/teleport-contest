## Sources

- `nethack-c/upstream/include/monsters.h:2790-2794`: the nurse monster uses `MS_NURSE`.
- `nethack-c/upstream/src/sounds.c:1160-1172`: `MS_NURSE` sets the cancelled fallback, then chooses weapon advice, armor/Healer cooperation advice, shirt advice, or relaxed examination speech.

## JS Changes

- Added explicit `MS_NURSE` handling in `tipHatMonsterNoise()`.
- Matched the C priority order: cancelled nurse, wielded weapon or weapon-tool, worn armor except shirt with the Healer role exception, worn shirt, then relaxed speech.
- Reused the existing inventory conventions for active equipment: `itemIsWielded()` for wielded weapons/tools and `isWornArmorItem()` for worn armor, including line text and `owornmask` state.
- Kept the implementation `tiphat()`-local; it does not introduce a shared `domonnoise()` or `#chat` speech table.

## Remaining Gaps

- Through `#tip`, the hero's helmet remains worn for the nurse speech check, so the shirt-only and no-armor relaxed branches are still masked by `uarmh`; direct coverage for those branches belongs with shared `#chat` or non-helmet `domonnoise()` integration.
- Visible humanoid nurses are still intercepted by the directed visible humanoid `tiphat()` response before `domonnoise()`, matching the current local path but leaving broad visible humanoid speech for another slice.
- The nurse equipment check is based on the JS inventory model's worn/wielded flags, line text, and `owornmask`; it does not add full C `uarm*` slot state.
