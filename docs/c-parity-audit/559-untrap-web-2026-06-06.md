# Web `#untrap`

## Scope

Port seen spider web handling for `#untrap`. This covers unoccupied adjacent webs, trapped monsters in webs, the plain failure branch, the failed-untrap forced web-entry branch, and trapped-monster web spread with `NOWEBMSG`-style message suppression.

The implementation uses deterministic command-level tests and does not use replay maps, hidden tests, fixed seeds, player names, or runtime shortcuts.

## C Reference

- `nethack-c/upstream/src/trap.c:5246` through `:5256` dispatches `dountrap()` through `could_untrap()` and `untrap()`.
- `nethack-c/upstream/src/trap.c:5289` through `:5329` computes `untrap_prob()` for webs.
- `nethack-c/upstream/src/trap.c:5480` through `:5524` handles failed untrap, `rnl(5)`, `Whoops...`, forced trap entry, and trapped-monster spread.
- `nethack-c/upstream/src/trap.c:5550` through `:5589` handles trapped-monster extraction and web removal success messages.
- `nethack-c/upstream/src/trap.c:5953` through `:5970` rejects untrapping while already trapped and dispatches seen `WEB` to `disarm_holdingtrap()`.
- `nethack-c/upstream/include/obj.h:213` through `:216` defines `is_blade()` for `#untrap` odds as weapon-class skills `P_DAGGER` through `P_SABER`, which excludes axes, mattocks, lances, and polearms.

## JS Change

- `js/cmd.js` now recognizes seen `WEB` targets in `untrapDirection` before falling through to squeaky-board or generic failure handling.
- Web `#untrap` uses C-shaped odds: base `3`, artifact blade odds `1`, non-webmaker no-blade/monster odds `7`, plus confusion/hallucination, blindness, stun, fumbling, and user-made trap modifiers.
- Web blade classification is separate from force-fight web classification. `#untrap` excludes axes and mattocks even though force-fight web cutting handles them.
- Success deletes unoccupied webs with C messages for no blade, ordinary blade, Sting, and Fire Brand. Trapped-monster success extracts the monster and leaves the web in place.
- Failure uses `rnl(5)`: zero prints `That/This/Your web is difficult to remove.`, while nonzero prints `Whoops...` and either forces hero web entry or applies trapped-monster spread.
- Trapped-monster spread rolls `rn2(3)`, reuses or creates a hero-square web, applies web trap state, and suppresses the ordinary `You are caught by...` web-entry message.

## Tests

- `#untrap removes a seen web without a blade`
- `#untrap cuts a seen web with an ordinary blade`
- `#untrap treats axes as non-blades for web odds`
- `#untrap removes a seen web with Sting artifact odds and message`
- `#untrap removes a seen web with Fire Brand artifact odds and message`
- `#untrap web failure can leave the hero in place`
- `#untrap web failure can move the hero into the web`
- `#untrap extracts a trapped monster from a seen web`
- `#untrap failed trapped-monster web can spread with NOWEBMSG behavior`

These tests drive the real extended command input, assert exact RNG calls, messages, trap persistence/deletion, hero position, web trap state, monster `mtrapped` state, and turn consumption.
