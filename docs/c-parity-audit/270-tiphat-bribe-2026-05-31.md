# C Parity Audit 270: Tiphat Bribe Fallthrough

## Sources

- `nethack-c/upstream/include/monflag.h:48-49`: `MS_BRIBE` immediately precedes `MS_CUSS`.
- `nethack-c/upstream/include/monsters.h:3090-3114`: demon princes such as Geryon, Dispater, and Baalzebub use `MS_BRIBE`.
- `nethack-c/upstream/src/sounds.c:1141-1155`: `MS_BRIBE` calls `demon_talk()` only for peaceful non-tame monsters; otherwise it falls through to `MS_CUSS`.
- `nethack-c/upstream/src/sounds.c:1151-1154`: peaceful cuss fallthrough is deterministic: lawful minions say `"It's not too late."`; other peaceful monsters say `"We're all doomed."`.
- `nethack-c/upstream/src/sounds.c:1449-1528`: worn-helmet `#tip` prints the doffing line, clears wait strategy before response, intercepts visible humanoids before `domonnoise()`, and maps invisible responders.
- `nethack-c/upstream/src/minion.c:309-340`: the peaceful non-tame `demon_talk()` bribe path uses gold demands, prompts, and RNG.
- `nethack-c/upstream/src/wizard.c:846-880`: hostile `MS_BRIBE` reaches `cuss()`, which has RNG-heavy Wizard, minion, and demon branches.

## JS Coverage

- Explicit `MS_BRIBE` now normalizes to `bribe` through the existing `MS_` sound-name path.
- `tipHatMonsterNoise()` defers peaceful non-tame bribe speech to the broader `demon_talk()` gap rather than synthesizing a cuss line.
- Tame peaceful `MS_BRIBE` now falls through to the same peaceful cuss helper used by `MS_CUSS`.
- Hostile `MS_BRIBE` falls through to the existing hostile cuss implementation, matching the C switch shape without adding new seed-fixed behavior.
- The peaceful cuss message is shared through `tipHatPeacefulCussNoise()` so `MS_BRIBE` and `MS_CUSS` stay aligned.

## Tests

Focused canaries in `test/shop-billing-helpers.test.mjs` cover:

- a tame peaceful invisible `MS_BRIBE` demon prince falling through to `"We're all doomed."` without RNG,
- a synthetic tame peaceful lawful-minion `MS_BRIBE` fixture falling through to `"It's not too late."` without RNG.

The lawful-minion briber is synthetic, but it directly protects the C fallthrough into the `is_lminion()` arm while staying seed-free.

## Remaining Gaps

- Peaceful non-tame `MS_BRIBE` still needs real `demon_talk()` behavior, including gold demand, offer prompt, teleport/removal, anger, and charisma/gold RNG.
- Hostile `MS_BRIBE` reuses the existing hostile cuss approximation; this slice does not expand Wizard/minion/demon cuss pager parity.
- Real demon prince inference remains data-dependent; this slice only covers explicit `MS_BRIBE` fixtures used by the directed helmet-tip tests.
- Broader shared `domonnoise()` and `#chat` are still not unified with directed helmet tipping.
