# C Parity Audit 267: Tiphat Bones Noise

## Sources

- `nethack-c/upstream/include/monflag.h:32-34`: `MS_BONES` is the skeleton bone-rattle sound.
- `nethack-c/upstream/include/monsters.h:2495-2505`: skeletons use `MS_BONES` and are humanoid.
- `nethack-c/upstream/src/sounds.c:688-714`: `domonnoise()` returns early for deaf heroes/silent non-shopkeepers and can remap special minds before the sound switch.
- `nethack-c/upstream/src/sounds.c:968-975`: `MS_BONES` prints the monster rattle, prints `You freeze for a moment.`, calls `nomul(-2)`, records `scared by rattling`, and sets `gn.nomovemsg = 0`.
- `nethack-c/upstream/src/sounds.c:1240-1241`: handled monster noise consumes command time.
- `nethack-c/upstream/src/sounds.c:1506-1528`: directed `tiphat()` intercepts visible humanoids before `domonnoise()`, so skeleton rattling is mainly reachable through an adjacent, responsive non-visible skeleton.
- `nethack-c/upstream/src/hack.c:4161-4186`: `nomul(-2)` records two helpless turns, and a null `nomovemsg` becomes the default `You can move again.` when the helpless period ends.

## JS Coverage

- `tipHatMonsterSound()` now infers `bones` for skeletons before the generic zombie groan branch.
- `tipHatMonsterHumanoid()` treats skeletons as humanoid so visible directed helmet tipping uses the C humanoid response path before any bone-rattle sound.
- The `bones` noise branch emits the C message order for the local tiphat path: source rattle first, then the hero freeze message.
- The branch sets the existing two-turn helpless state and default wake message, matching C's `nomul(-2)` plus null `nomovemsg` behavior.
- No RNG is consumed in the skeleton rattle path.

## Tests

Focused canaries in `test/shop-billing-helpers.test.mjs` cover:

- inferred invisible skeleton `MS_BONES` rattling and freezing the hero without RNG,
- explicit `MS_BONES` dispatch on a non-skeleton fixture without RNG,
- visible skeletons staying on the visible humanoid branch before bones noise,
- frozen invisible skeletons being nonresponsive, preserving wait state, and not freezing the hero.

## Remaining Gaps

- This remains local to directed helmet tipping; broad shared `domonnoise()` and `#chat` still do not share a unified implementation.
- JS does not currently expose C's `gm.multi_reason = "scared by rattling"` in a status/reason field for this branch.
- Shopkeeper `MS_SELL`, quest leaders/nemeses/guardians, priests, vampires, Riders, Oracle, seduction, and bribe speech are still separate sound gaps.
